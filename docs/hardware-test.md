# ハードウェアテスト版

使用者提供のプログラムを `firmware/hardware_test/hardware_test.ino` に原文のまま保存しています。シリアル通信だけの `firmware/mosquito_trap/mosquito_trap.ino` とは別のスケッチです。

このテスト版は LED・受光・サーボを個別に操作します。蚊の検出から吸引への自動連動、影の移動追跡、視差からの奥行き推定は未実装です。ヒーターや555拡散回路は操作しません。

## 開き方と環境

Arduino IDE で `firmware/hardware_test/hardware_test.ino` を開きます。ESP32Servo **3.2.1** が必要です。手元の ESP32 コアは **3.3.11** です。初期スケッチの既存 CI は 3.3.10 を維持し、このテスト版は別ジョブで 3.3.11 を使用します。

設定は Flash Size **16MB**、PSRAM **OPI PSRAM**（搭載8MB）。USB CDC は接続端子に合わせます。シリアルモニタは **115200 baud**、コマンドの数字を1文字ずつ送信します。

## ピン割り当て（提供コード）

| 用途 | GPIO |
| --- | --- |
| MUX1 の信号入力 | 1 |
| MUX2 の信号入力 | 2 |
| 共通の選択線 S0 / S1 / S2 / S3 | 6 / 7 / 8 / 9 |
| 左 / 右 赤外線 LED | 10 / 11 |
| サーボ | 16 |

PT1〜PT16 は MUX1 のチャンネル0〜15、PT17〜PT18 は MUX2 のチャンネル0〜1を読み取ります。MUX の製品型番・電源・有効化端子と、PT番号から横6個×3列への物理的な対応は未確認です。これはコード上の割り当てであり、実物の配線確認は別途必要です。

## テストコマンド

| 入力 | 動作 |
| --- | --- |
| `1` | 左LEDを1秒、右LEDを1秒、両方消灯を1秒 |
| `2` | LED消灯時のPT1〜PT18のADC値を表示 |
| `3` | 消灯・左点灯・右点灯を読み、背景値−点灯値を表示（負値は0） |
| `4` | 最初の測定を基準に、左右いずれかの信号比が0.75未満の点があれば影ありと表示。リセットまで継続 |
| `5` | サーボで1回押下・解放 |
| `6` | 2回押下・解放→3秒待機→1回押下・解放 |

受光は12bit ADC、各点4回の平均です。MUX切替後10µs、LED切替後300µsの待ち時間をコードで指定しています。左右の18点は順番に読み取るため、同時測定ではありません。これらの待ち時間やしきい値の実機での妥当性は未検証です。

## サーボと掃除機

コード上の設定は待機20°、押下65°、50Hz、attach のパルス範囲500〜2400µsです。起動時にもサーボを有効化して待機角へ動かします。まずボタンに接触しない状態で角度と可動範囲を確認します。

`5` は押下250ms・解放後500ms待機。`6` は各押下250ms・解放後300ms待機で、2回目の解放後にさらに3000ms待機します。このため、強吸引の実時間が厳密に3秒という意味ではありません。

**`6` は掃除機が停止している状態から実行します。** `5` や手動操作で状態を変えた後は、停止状態を確認してから実行します。押下成功や掃除機の状態を読み返す機能はありません。サーボを解放しただけでは掃除機は停止しません。

## コードを使用する前に把握する点

- `4` は無限ループに入り、他のコマンドを受け付けません。停止・再校正にはボードのリセットが必要です。
- 基準信号が0の点は1に補正されます。その点の現在信号が0なら比率0となり、影ありになります。照明が届かない点や未接続の入力でも影が出る可能性があるため、まず`2`と`3`で信号を確認します。
- `背景−点灯値` は、受光でADC値が下がる配線を前提としています。逆極性の回路では負値が0に切り詰められます。
- `4` の影あり表示はサーボを動かしません。`6` は独立した手動テストです。
- 校正は1回の測定のみで、再校正や複数回の検出確認、遮光の移動解析はありません。
- `delay` を使うテスト中は別コマンドを処理しません。`6` を途中で止めるシリアルコマンドもありません。

現時点は提供コードの保存とコンパイル確認の段階です。実機への書き込み、配線検証、影の検出性能、サーボ押下・捕獲の動作は未検証です。
