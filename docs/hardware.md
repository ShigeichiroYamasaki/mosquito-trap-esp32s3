# ハードウェア

## 採用する構成

| 部分 | 設計方針 |
| --- | --- |
| 制御ボード | Freenove ESP32-S3 Board Lite（カメラなし） |
| Flash Size 設定 | 16MB（使用者確認済み） |
| PSRAM 設定 | OPI PSRAM、容量 8MB（使用者確認済み） |
| 開発 | macOS / Arduino IDE / USB 接続 |
| CO₂ 誘引源 | 重曹とクエン酸で CO₂ を発生 |
| 人工皮膚 | 人間が半日以上履いた靴下を 36°C のヒーターで加温 |
| ケース | 10cm 角。CO₂ 噴出口とヒーター付き人工皮膚を格納 |
| 拡散ファン | ケース下面に配置、電源 5V、CO₂ と匂いを拡散 |
| 拡散リズム | 555 タイマー IC で 4〜6秒間隔の間欠動作を実装 |
| 発光部 | 赤外線 LED 2個を時間差で交互に点灯し、視差を表現 |
| 受光部 | Moechando 940nm・5mm 赤外線レシーバー、横6個 × 3列（計18個）を現在配置 |
| 検出 | 蚊の影とその動きを認識 |
| 捕獲 | プッシュボタン式掃除機。停止から1回で弱、2回で強、3回で停止。検出時にサーボで2回押し、吸引後に1回押して停止 |

詳細は [誘引・検出・吸引の機構](./mechanism.md) を参照してください。上記は設計方針であり、実機での動作確認を示すものではありません。

## 検出・吸引制御部の部品構成

| 部品 | 数量 | 仕様・用途 |
| --- | --- | --- |
| Freenove ESP32-S3 Board Lite | 1台 | カメラなし、Flash 16MB、PSRAM 8MB（OPI） |
| フォトトランジスタ | 18個 | Moechando 940nm・5mm、横6個×3列 |
| 赤外線 LED | 2個 | 時間差で交互点灯 |
| サーボモータ | 1個 | 掃除機のボタンを操作 |
| アナログマルチプレクサ CD74HC4067 | 2個 | 18個の受光信号を切り替えてADCに入力 |

この一覧は検出・吸引制御部の構成です。CO₂ 発生部、人工皮膚、ヒーター、555タイマー、拡散ファン、掃除機もシステムに含みます。

### CD74HC4067 とテストコードの対応

CD74HC4067 は16:1のアナログマルチプレクサで、2個で計32入力分の切替経路を用意できます。現在のテストコードはそのうち18入力を使用します。複数のアナログ信号を順番にADCへ接続する方式で、同時に18点を変換するものではありません。[TI 公式仕様](https://www.ti.com/product/CD74HC4067)

| コード上の接続 | 使用入力 | ESP32-S3 |
| --- | --- | --- |
| MUX1 | CH0〜CH15：PT1〜PT16 | 共通信号端子を GPIO1（ADC）へ |
| MUX2 | CH0〜CH1：PT17〜PT18 | 共通信号端子を GPIO2（ADC）へ |
| 共通選択線 | S0 / S1 / S2 / S3 | GPIO6 / 7 / 8 / 9 |

2個のMUXは選択線を共有し、信号端子は別々のADC入力へ接続するコード構成です。MUX2のCH2〜CH15は読み取り対象外です。MUXの電源・有効化端子の実配線と、PT番号から受光配列の位置への対応は確認予定です。

## 単体受光テストの結果

使用者報告では、フォトトランジスタのコレクタ側抵抗は **10kΩで感度不足、100kΩで十分な感度**でした。抵抗増加による応答の遅れも確認項目です。応答時間の数値と18点配列での適合性は未確認です。[実験記録](./roadmap.md)に回路・測定条件と評価範囲を記載しています。

## 使用ボード

使用するボードは **Freenove ESP32-S3 Board Lite（カメラなし）**です。使用者から Board Lite（カメラなし）と指定されています。モジュール刻印は未確認です。Flash Size は使用者の確認により **16MB** として確定しました。

Arduino IDE の設定は **Flash Size: 16MB / PSRAM: OPI PSRAM（8MB）** です。これらは使用者が確認した設定値であり、この構成での統合動作は未検証です。USB 設定は引き続き確認する項目です。

最初はボード単体の USB 通信を確認します。ヒーターやサーボの電源は部品仕様に合わせて設計し、GPIO から負荷を直接駆動しません。

GPIO 番号は型番と回路図を確認してから割り当てます。初期スケッチは GPIO を操作しません。[テスト版](./hardware-test.md)は記載の GPIO を操作し、起動時にもサーボを動かします。
