### CD74HC4067 とテストコードの対応

CD74HC4067 は16:1のアナログマルチプレクサで、2個で計32入力分の切替経路を用意できます。現在のテストコードはそのうち18入力を使用します。複数のアナログ信号を順番にADCへ接続する方式で、同時に18点を変換するものではありません。[TI 公式仕様](https://www.ti.com/product/CD74HC4067)

| コード上の接続 | 使用入力 | ESP32-S3 |
| --- | --- | --- |
| MUX1 | CH0〜CH15：PT1〜PT16 | 共通信号端子を GPIO1（ADC）へ |
| MUX2 | CH0〜CH1：PT17〜PT18 | 共通信号端子を GPIO2（ADC）へ |
| 共通選択線 | S0 / S1 / S2 / S3 | GPIO6 / 7 / 8 / 9 |

2個のMUXは選択線を共有し、信号端子は別々のADC入力へ接続するコード構成です。MUX2のCH2〜CH15は読み取り対象外です。使用者から提示された電源・EN・信号線の配線を以下に記録します。PT番号から横6個×3列の物理的位置への対応と、実機での全入力の動作は未確認です。

### MUXの配線（使用者指定）

| CD74HC4067端子 | MUX1 | MUX2 |
| --- | --- | --- |
| VCC | 3.3V | 3.3V |
| GND | ESP32と共通のGND | ESP32と共通のGND |
| EN | GND | GND |
| SIG | GPIO1 | GPIO2 |
| S0 | GPIO6 | GPIO6 |
| S1 | GPIO7 | GPIO7 |
| S2 | GPIO8 | GPIO8 |
| S3 | GPIO9 | GPIO9 |

ENをGNDに固定し、両MUXを有効にする構成です。SIGはGPIO1とGPIO2に分け、選択線S0〜S3を共有します。端子の呼称C0〜C15とCH0〜CH15は、この文書では同じチャンネル番号を表します。

### フォトトランジスタ18個の配線（使用者指定）

各フォトトランジスタに100kΩのコレクタ側抵抗を1本ずつ接続します（計18本）。抵抗下端・コレクタ・MUX入力を同じ接点に接続し、エミッタは共通GNDに接続します。

```text
     3.3V
       │
     100kΩ    ← 各受光素子に1本
       │
       ├──── MUX Cn
       │
   Collector
 フォトトランジスタ
    Emitter
       │
      GND
```

- MUX1 C0〜C15：PT1〜PT16
- MUX2 C0〜C1：PT17〜PT18

これは18点配列に使用する指定配線です。100kΩの単体感度試験結果と、MUX経由の18点読み取り・応答時間の検証は区別します。

### LEDとサーボの信号線（使用者指定）

| ESP32-S3 Board Lite | 接続先 |
| --- | --- |
| GPIO10 | 左赤外線LED制御 |
| GPIO11 | 右赤外線LED制御 |
| GPIO16 | サーボ信号 |

以上のGPIOとMUXチャンネル割り当ては、提供されたハードウェアテストコードの定数・読み取り処理と一致しています。LED駆動回路は下記の使用者指定です。サーボの電源・信号配線も下記の使用者指定です。

### 赤外線LEDの駆動回路（使用者指定）

左右それぞれに以下の回路を1組ずつ用意します。必要数は赤外線LED・2N2222・330Ω抵抗・1kΩ抵抗が各2個です。

```text
+5V ── 330Ω ── IR LED アノード
IR LED カソード ── 2N2222 Collector
2N2222 Emitter ── 共通GND
ESP32 GPIO ── 1kΩ ── 2N2222 Base

左：GPIO10    右：GPIO11
```

2N2222を使うローサイド駆動の指定です。5V電源のGNDとESP32・受光回路のGNDを共通にします。GPIOをHIGHにして点灯するテストコードと対応します。実機での点灯と電流は未検証です。

使用者から提示された端子図は次のとおりです。

```text
 2N2222
   ___
 /_____\
  | | |
  E B C
```

この端子図のメーカー・製品型番・パッケージ・見る方向は未確認です。E/B/Cの実端子番号は、使用部品のデータシートと照合して確定します。上の図を2N2222全製品に共通する端子順として扱いません。

LEDの順方向電圧・定格電流と2N2222の電圧降下が未確認のため、330Ωでの実電流はまだ確定していません。単体受光テストの常時点灯回路に使った220Ωと、今回指定された駆動回路の330Ωは別の試験条件として記録します。

### サーボの配線（使用者指定）

| サーボ線 | 接続先 |
| --- | --- |
| 赤 | +5V |
| 黒／茶 | 共通GND |
| 信号 | ESP32-S3 GPIO16 |

サーボ電源のGNDはESP32・MUX・受光回路・LED駆動回路と共通にします。5Vの給電元・必要電流容量とサーボ型番は未確定です。この配線指定は、MacのUSB電源だけで全負荷を駆動できることを確認したものではありません。

テストコードの `SERVO_PIN = 16` と一致します。起動時には待機角20°へ動き、押下角は65°に設定されています。これらの角度でボタンを押せるか、取り付けた実機での確認は別途必要です。

## CO₂ファン用4秒タイマー {#fan-timer}

NE555を5Vで動作させ、IRLZ44NでCO₂専用5Vファンを間欠駆動します。**約1.98秒運転＋約2.00秒停止＝約3.98秒周期**の設計です。部品誤差や起動時の過渡動作を含む実測値は未確認です。ヒーター電源も5Vですが、ヒーターはこのタイマーで断続運転せず、温度制御を別に設計します。

| 部品 | 値・用途 |
| --- | --- |
| RA | 1kΩ |
| RB | 130kΩ（120kΩ＋10kΩの直列でも可） |
| C | 22µF、定格10V以上の電解コンデンサー |
| CONT用 | 10nF、NE555の5番とGND間 |
| 電源バイパス | 100nF、NE555の8番と1番の直近 |
| 反転・ゲート駆動 | 2N2222 × 1、ベース抵抗10kΩ |
| ゲート用 | プルアップ4.7kΩ、直列100Ω、プルダウン100kΩ |
| ファンスイッチ | IRLZ44N |
| ファン保護ダイオード | ファンの電流・電圧に合わせて選定 |

### NE555の発振回路

```text
+5V ── RA 1kΩ ──┬── RB 130kΩ ──┬── C 22µF ── GND
                 │               │   ＋    −
               7番             2番・6番

8番 VCC   → +5V
4番 RESET → +5V
1番 GND   → GND
5番 CONT  → 10nF → GND
3番 OUT   → 下記のゲート駆動回路
```

定常動作時の計算式は次のとおりです。[TI NE555データシート](https://www.ti.com/lit/ds/symlink/ne555.pdf)

```text
tHIGH = 0.693 × (RA + RB) × C ≒ 2.00秒
tLOW  = 0.693 × RB × C        ≒ 1.98秒
周期  = tHIGH + tLOW          ≒ 3.98秒
```

22µFの容量誤差により周期は変わります。調整する場合はRBを100kΩ＋100kΩ半固定抵抗に置き換え、実測で4秒に合わせます。半固定抵抗は摺動端子と一方の端子を接続して使用します。

### IRLZ44Nによるファン駆動

NE555の5V動作時のHIGH出力は電源電圧まで上がるとは限りません。IRLZ44Nのゲートに5Vに近い電圧を与えるため、2N2222とプルアップ抵抗を追加します。[IRLZ44Nデータシート](https://www.infineon.com/assets/row/public/documents/24/49/infineon-irlz44n-datasheet-en.pdf)

```text
NE555 3番 ── 10kΩ ── 2N2222 Base
                       Emitter ── GND

+5V ── 4.7kΩ ──┬── 100Ω ── IRLZ44N Gate
                │
          2N2222 Collector

IRLZ44N Gate ── 100kΩ ── GND
IRLZ44N Source ── GND

+5V ── ファン ＋
       ファン − ── IRLZ44N Drain

保護ダイオード：カソード → +5V、アノード → Drain
```

信号が反転するため、NE555のLOW中にファンが運転し、HIGH中に停止します。GNDは共通にします。2N2222の端子配列は製品のデータシートで確認します。電源容量と保護ダイオードの定格は、ファンの起動電流に合わせて選びます。

ファンの立ち上がりとチューブ内の滞留により、CO₂濃度の波形は電気的なON/OFF波形と異なります。接近位置の濃度変化を測定して評価します。
