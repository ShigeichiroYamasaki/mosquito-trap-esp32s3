# ハードウェア

## 採用する構成

| 部分 | 設計方針 |
| --- | --- |
| 制御ボード | Freenove ESP32-S3 |
| Flash Size 設定 | 16MB（使用者確認済み） |
| PSRAM 設定 | OPI PSRAM、容量 8MB（使用者確認済み） |
| 開発 | macOS / Arduino IDE / USB 接続 |
| CO₂ 誘引源 | 重曹とクエン酸で CO₂ を発生 |
| 人工皮膚 | 人間が半日以上履いた靴下を 36°C のヒーターで加温 |
| ケース | 10cm 角。CO₂ 噴出口とヒーター付き人工皮膚を格納 |
| 拡散ファン | ケース下面に配置、電源 5V、CO₂ と匂いを拡散 |
| 拡散リズム | 555 タイマー IC で 4〜6秒間隔の間欠動作を実装 |
| 発光部 | 赤外線 LED |
| 受光部 | トンボの複眼を模した赤外線受光素子配列 |
| 検出 | 蚊の影とその動きを認識 |
| 捕獲 | サーボモータで掃除機のトリガーを操作して吸引 |

詳細は [誘引・検出・吸引の機構](./mechanism.md) を参照してください。上記は設計方針であり、実機での動作確認を示すものではありません。

## 使用ボード

使用するボードは **Freenove ESP32-S3**です。詳細な製品品番とモジュール刻印は未確認です。Flash Size は使用者の確認により **16MB** として確定しました。

Arduino IDE の設定は **Flash Size: 16MB / PSRAM: OPI PSRAM（8MB）** です。これらは使用者が確認した設定値であり、実機への書き込み・動作検証はまだ行っていません。USB 設定は引き続き確認する項目です。

## 実装前に決めること

| 項目 | 状態 |
| --- | --- |
| ボードの詳細品番・モジュール刻印、USB 端子 | 実物・製品資料で確認予定 |
| CO₂ 発生部の構造・放出条件 | 未確定 |
| ケースの高さ・内外寸、開口部、ファンの送風方向 | 未確定 |
| 5V ファンの型番・電流、555 の型番・定数・駆動回路 | 未確定 |
| ファンの ON/OFF 時間の内訳・周期調整方式 | 未確定 |
| ヒーター・温度センサー・駆動回路 | 未確定 |
| 赤外線 LED・受光素子の型番と配列・読み取り回路 | 未確定 |
| 掃除機・サーボの型番と機械的な取付方法 | 未確定 |
| 電源容量・GPIO 割当・配線 | 未確定 |

最初はボード単体の USB 通信を確認します。ヒーターやサーボの電源は部品仕様に合わせて設計し、GPIO から負荷を直接駆動しません。

GPIO 番号は型番と回路図を確認してから割り当てます。現行スケッチは GPIO を操作しません。
