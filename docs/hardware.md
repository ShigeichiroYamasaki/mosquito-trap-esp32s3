# ハードウェア

## 確定していること

- MCU: ESP32-S3
- 開発用 PC: macOS
- 開発・書き込み: Arduino IDE、USB 接続

## 実装前に決めること

| 項目 | 状態 |
| --- | --- |
| ボードのメーカー・製品名 | 未確定 |
| Flash / PSRAM 容量 | 未確定 |
| USB 端子の種類 | 未確定 |
| 捕獲方式・誘引方法 | 未確定 |
| ファン、センサー、電源 | 未確定 |
| GPIO 割当・駆動回路 | 未確定 |

最初はボード単体の USB 通信を確認します。ファン等の負荷を GPIO から直接駆動せず、部品仕様に合う駆動回路と電源を設計してから追加します。

GPIO 番号は型番と回路図を確認してから割り当てます。現行スケッチは GPIO を操作しません。
