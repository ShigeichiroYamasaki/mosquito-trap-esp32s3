# 開発計画・実験記録

誘引・捕獲方式は [機構仕様](./mechanism.md) の方針で進めます。以下の各段階は、まだ実機での完了を確認していません。

| 段階 | 完了条件 |
| --- | --- |
| 1. 接続確認 | 製品型番を記録し、Mac から書き込み、毎秒のログを確認 |
| 2. 人工皮膚・CO₂ 発生部 | 10cm 角ケースに噴出口・人工皮膚と下面ファンを組み込み、555 による 4〜6秒間隔の拡散動作と温度・放出条件を測定 |
| 3. 影の検出 | LED と単一受光素子で遮光信号を取得し、蚊の影が検出可能か評価 |
| 4. 複眼状の配列 | 横6個 × 3列（18個）のデータを2個の LED の交互点灯と対応付け、光源ごとの影の違い・移動・誤検出・見逃しを評価 |
| 5. 吸引機構 | サーボで掃除機のトリガーを押下・解放でき、吸引開始までの遅延を測定 |
| 6. 統合試作 | 接近検出 → 吸引 → 解放・待機の一連の動作と異常時の停止を確認 |
| 7. 効果測定 | CO₂・匂い・加温の条件を記録し、接近数・捕獲数・誤作動・消費電力を比較 |
