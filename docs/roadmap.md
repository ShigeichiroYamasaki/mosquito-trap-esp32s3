# 開発計画・実験記録

誘引・捕獲方式は [機構仕様](./mechanism.md) の方針で進めます。単一受光素子の抵抗比較について、使用者から実験結果が報告されています。各段階全体の完了や蚊の検出・捕獲性能は未確認です。

| 段階 | 完了条件 |
| --- | --- |
| 1. 接続確認 | 製品型番を記録し、Mac から書き込み、毎秒のログを確認 |
| 2. 人工皮膚・CO₂ 発生部 | 人工皮膚の10cm角ケースとCO₂専用流路を分離し、555による4〜6秒間隔の濃度変化、温度、靴下の揺れを測定 |
| 3. 影の検出 | LED と単一受光素子で遮光信号を取得し、蚊の影が検出可能か評価 |
| 4. 複眼状の配列 | 横6個 × 3列（18個）のデータを2個の LED の交互点灯と対応付け、光源ごとの影の違い・移動・誤検出・見逃しを評価 |
| 5. 吸引機構 | 停止からサーボの2回プッシュで強吸引、さらに1回で停止できることを確認し、必要な押下間隔と遅延を測定 |
| 6. 統合試作 | 接近検出 → 2回プッシュ → 強吸引 → 1回プッシュ → 停止・待機を確認し、再検出や状態ずれへの対応を検証 |
| 7. 効果測定 | CO₂・匂い・加温の条件を記録し、接近数・捕獲数・誤作動・消費電力を比較 |

## 検出システムの評価段階

コードの実装・コンパイルと、実機での性能確認は別に管理します。[設計書](./detection-design.md)の仮しきい値は、以下の順で測定して調整します。

|段階|実装状況|実機で確認すること|
|---|---|---|
|3相測定|実装済み|OFF/左/右の整定、実フレーム周期、背景光変動|
|左右別校正|実装済み|18点の平均・ばらつき・飽和・無効点の分布|
|影の追跡|実装済み|通過・静止・広域遮光・靴下やファンの揺れの区別|
|検出と吸引の連動|実装済み、起動時無効|消失確認と2回押下の遅延、捕獲率|
|左右照明の視差|次期、未実装|実寸校正・左右対応付け・時間差の移動補正|
|36点化|将来案|32chを超えるMUX構成と走査時間の再検討|

測定用スケッチは4相（OFF/左/OFF/右）で取得します。実行版の3相（OFF/左/右）と取り違えず、使用スケッチとコミットを記録します。

## 掃除機の比較・変更計画

現在はDCモーターのコンパクト掃除機を使用し、AC電源のハンディ掃除機への変更は将来の検討事項とします。モーターや内部回路は改造せず、サーボによる外部スイッチ操作を前提とします。

比較時は吸込口の風量・負圧、検出から実際の吸引開始までの時間、捕獲率、騒音、寸法、電源条件を記録します。AC／DCだけでは性能順位を決めません。交換機のスイッチ挙動を確認し、現在の「1回で弱・2回で強・3回で停止」をそのまま適用しないようにします。

## 実験結果：コレクタ抵抗の比較

使用者から報告された単一フォトトランジスタのテスト結果です。実施日、遮光・照射時のADC実測値、応答時間の数値は未提示です。

### 回路と読み取り条件

- 3.3V → コレクタ側抵抗 → コレクタ。コレクタの接点を GPIO1（ADC）へ接続し、エミッタは GND。
- 赤外線 LED は 5V → 220Ω → 940nm LED → GND の常時点灯回路。
- 提示された単体テストコードは GPIO1 を12bitで読み、115200 baudで出力し、各ループで10ms待機。
- 回路図・コード中の「ESP32-S3 Sense」という表記と、プロジェクトの Freenove ESP32-S3 との対応は未確認です。

### 報告された結果

| コレクタ側抵抗 | 感度についての評価 |
| --- | --- |
| 10kΩ | 感度が低すぎた |
| 100kΩ | 十分な感度が得られた |

使用者から、抵抗が大きくなると反応速度が遅くなる点も報告されています。応答時間の数値や比較波形は未提示で、定量評価はまだありません。100kΩを感度確認できた試験条件として記録し、18点配列での最終抵抗値は別途検証します。

### 次に確認すること

同じ照明・距離・遮光条件で、明時／遮光時のADC値、ばらつき、遮光開始・解除から信号が落ち着くまでの時間を記録します。約10ms間隔のシリアル出力だけでは、それより短い応答時間は評価できません。

18点配列へ適用するときは、使用スケッチのLED・MUX切替後の待ち時間で読み取りが安定するか確認します。個別テスト版は300µs／10µs、実行版は2000µs／50µsという別の仮設定です。この感度評価だけでは、これらの待ち時間の妥当性や蚊の通過検出性能は判断できません。
