# 赤外線LED・フォトトランジスタの測定

`firmware/optical_measure/optical_measure.ino` は、10cmの光路で左右LEDの光が18点へ届いているか、小さな遮光が数値に現れるかを調べる専用プログラムです。実行版と別のスケッチで、GPIO16を設定せず、サーボ・掃除機・ヒーターは操作しません。

[GitHub：測定プログラム一式](https://github.com/ShigeichiroYamasaki/mosquito-trap-esp32s3/tree/main/firmware/optical_measure)

## できること

- 消灯→左LED→消灯→右LEDの順に18点を測定。
- ADC平均・最小・最大と、左右それぞれの「消灯値−点灯値」を保存。負の差分も保持。
- Web画面で18点の最新値と、今回の全フレームの平均差分を表示。
- ADC端付近、小さい差分、負の差分を色で示す。
- 1〜120フレームを収集し、途中停止または完了後にCSVをダウンロード。
- USBシリアルだけでも開始・停止・CSV出力が可能。

実機でのADC・光学応答・Wi-Fi接続は未検証です。プログラムのコンパイルと計算・画面状態の単体テストを実施します。

## 書き込みと接続

1. `optical_measure` フォルダー一式を取得し、`optical_measure.ino` をArduino IDEで開きます。`Measurement.h` と `WebUi.h` も同じフォルダーに必要です。
2. ESP32コア **3.3.11**、Flash Size **16MB**、PSRAM **OPI PSRAM**（8MB）を使用します。追加ライブラリのインストールは不要です。
3. USB端子に合う設定で書き込み、シリアルモニタを **115200 baud** で開きます。
4. MacまたはスマートフォンをWi-Fi **Deneuve2-Measure** に接続します。パスワードは **deneuve2measure** です。
5. ブラウザーで **http://192.168.4.1/** を開きます。実際のアドレスはシリアルにも表示します。

ESP32が専用のアクセスポイントを作るため、自宅Wi-FiのSSID・パスワードは不要です。このネットワークからインターネット接続は提供しません。測定後は普段のWi-Fiへ戻してください。アクセスポイントの名前・パスワードはスケッチの `WiFi.softAP` で変更できます。

起動直後はLEDが消灯し、測定開始を待ちます。元の実行版が掃除機を運転中だった場合、書き換えだけで停止はしないため、測定前に掃除機を停止してください。

## 最初の測定

1. 距離100mm、抵抗100kΩの実配線を用意し、光路を遮らずラベルを **遮光なし** にします。
2. 既定の30フレームで開始。約7.5秒が目安ですが、走査・通信により延びます。
3. 完了後に **CSVを保存** を押します。
4. 細い不透明な物を光路に置き、ラベルを **遮光あり** にして同じ設定で測定し、別のCSVとして保存します。
5. 左右それぞれについて、中央と端の受光素子の差分を比較します。

新しい測定は前回データを上書きします。最大120フレームをRAMへ保持し、再起動で消えます。開始前にCSVを保存してください。「途中で停止」でも取得済みの完全なフレームを保存できます。測定終了・停止時は両LEDを消灯します。

## 変更できる条件

| 項目 | 初期値 | 範囲・意味 |
| --- | --- | --- |
| フレーム数 | 30 | 1〜120 |
| LED切替後の待ち | 2000µs | 50〜20000µs。消灯後にも同じ待ちを使用 |
| MUX切替後の待ち | 50µs | 5〜1000µs。待機後の最初のADC変換を破棄 |
| ADC平均回数 | 8 | 1〜32 |
| フレーム開始間隔 | 250ms | 100〜5000ms。走査が長ければ指定間隔を超える |
| 距離 | 100mm | 1〜2000mm、記録用 |
| 抵抗 | 100kΩ | 1〜1000kΩ、記録用 |
| ラベル | open | open / shadow / ambient |

ラベル・距離・抵抗は実際の部品や動作を変更しません。`ambient`もLEDを同じ順序で点灯するため、外光条件を手で変えて比較する際の記録ラベルとして使います。

100kΩでの安定待ち時間は未確定なので、初期値は実行版より長めにしています。2000µsで十分と保証するものではありません。同条件で待ち時間を変え、値が変わらなくなるか確認します。この試験は待ち時間の比較であり、素子の立上り・立下り時間を直接測るものではありません。

## 表とCSVの読み方

左差分＝消灯L−左点灯、右差分＝消灯R−右点灯です。背景は左右の直前にそれぞれ測り、負値は切り捨てません。4相・各受光点は順次取得するため、同時刻の画像ではありません。

- **ADC端付近**：いずれかの平均が20以下または4075以上。飽和・断線を確定する診断ではありません。
- **小さい差分**：左右どちらかが20未満。ADC単位の任意の注意目安です。
- **負の差分**：配線極性、外光変動、測定中の遮光変化などを確認します。
- **最大振れ幅**：4相のうち最大の「ADCサンプル最大−最小」。平均に使った短時間のサンプルのばらつきで、全セッションのノイズ幅ではありません。

CSVは1フレームあたり18行、最大2160行です。各行に測定条件、フレーム番号、起動後の開始時刻、走査時間、4相の走査開始オフセット、PT番号・MUX番号・チャンネル、4相の平均・最小・最大、左右差分を保存します。時刻は実際の日付ではなく、`millis()`・`micros()`ベースです。相の時刻はその相の先頭の走査開始で、各PTの厳密な取得時刻ではありません。

ADCは12bit、GPIO1・GPIO2の減衰設定は `ADC_11db`。電圧への換算・校正は行いません。実測の走査時間とフレーム時刻をCSVで確認してください。

## USBシリアルで使う

115200 baud、改行ありで次を送ります。

| コマンド | 動作 |
| --- | --- |
| `open` | 遮光なしラベルで新規測定 |
| `shadow` | 遮光ありラベルで新規測定 |
| `ambient` | 外光比較ラベルで新規測定 |
| `stop` | 測定を停止、LED消灯 |
| `csv` | 停止後、保存済みデータをCSV形式でシリアルへ出力 |

測定数・待ち時間などは初期値または最後にWebで開始した条件を使います。`#`で始まる行は進行メッセージです。CSVとして保存するときはヘッダー `session,condition,...` からデータ行までを取得してください。シリアルの開始コマンドも前回データを置き換えます。

## 配線と制約

[既存の配線仕様](./hardware.md)を使います。MUX1のC0〜C15がPT1〜PT16、MUX2のC0〜C1がPT17〜PT18。選択線はGPIO6〜9、ADCはGPIO1・2、LEDはGPIO10・11です。PTの物理的位置は仮定せず、表はPT番号順に表示します。

測定中の停止要求は現在の4相走査が終わってから処理します。高速波形を取得するオシロスコープの代わりにはなりません。WebやCSV出力と無関係な厳密な周期測定も保証しません。複数ブラウザーが同時に操作すると同じ測定状態を共有するため、1台から操作してください。
