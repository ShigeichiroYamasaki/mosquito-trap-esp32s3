# 自動検出・Webログ実行版

`firmware/deneuve_runtime/deneuve_runtime.ino` は、[複眼方式の検出システム](./detection-design.md)を動かすプログラムです。3相フレーム、左右別の品質付き校正、同じ照明での影の追跡を実装しています。視差による奥行き判定は次期の計画です。

## 処理の流れ

![3相の測定と左右差分](/detection/frame.svg)

![初期校正による正規化と無効点の除外](/detection/calibration.svg)

左右を独立に追跡し、小さな影が短時間で移動・消失すると候補を記録します。図と全判定条件は[設計書](./detection-design.md)を参照してください。

## 開始手順

1. Arduino IDEで上記スケッチを開く。ESP32コア3.3.11、ESP32Servo 3.2.1、Flash 16MB、OPI PSRAMを選ぶ。
2. `secrets.example.h` を `secrets.h` にコピーしてWi-Fi設定を入力。接続できなければ10秒後にオフラインで継続する。
3. [配線](./hardware.md)を確認し、光路を空けて起動。サーボは待機角に動くが、自動吸引は無効で開始する。
4. 115200 baudのシリアルで80フレームの校正結果を確認する。`led,pixel,baseline,sd,valid` のCSVが表示される。valid=0の点は光量・配線・飽和を調べる。
5. Wi-Fi接続時はシリアルに出たIPアドレスを同じLANのブラウザで開く。校正表、走査時間・フレーム周期、検出ログを確認する。
6. 掃除機を停止状態にして、シリアルへ `a` を送ると自動吸引有効。`d`は新規吸引無効。無効かつシーケンス待機中の `c` で再校正する。

`d`を送っても進行中の押下シーケンスは最後の停止押下まで継続します。リセットや電源断では掃除機は停止しません。物理的なボタン成功・掃除機状態の確認機能はありません。

## ログ

`/` は3秒更新のWeb画面、`/json`は診断情報です。JSONには `frameUs`（走査時間）、`periodUs`（開始間隔）、`phaseUs`（各相の読取開始オフセット）、`armed`、`healthy`、最新50件の候補ログがあります。時刻は起動後の時間です。

イベントは影の消失時に確定します。active/total/motion/local/cx/cyは直前の影の左右最大値合成による診断値で、左右独立トラッカーのスコアや実距離ではありません。ログ件数は捕獲数ではなく、再開始制限中や自動吸引無効でも記録します。再起動でログは消えます。

Web画面はESP32が提供し、GitHub Pagesへの測定データ送信はしません。LAN内のWeb認証はありません。

しきい値、消失確認による遅延、吸引機構の応答、実機での評価手順は[設計書](./detection-design.md)を参照してください。コンパイル成功は実機捕獲性能の確認ではありません。
