# 誘引・検出・吸引の機構

このページは、2026年9月10日に提示された構想を設計仕様として記録したものです。誘引効果、蚊の影の検出性能、捕獲率は未検証で、制御ソフトは未実装です。

## 人工皮膚の定義

**人間が半日以上履いた靴下を、36°C のヒーターで加温したものを「人工皮膚」と呼びます。** 靴下の匂いと加温によって人間の存在・体温を模倣し、蚊を近づける構想です。

36°C は指定されたヒーターの温度です。実装時には、温度センサーの位置と、ヒーター温度・靴下表面温度の関係を確認します。靴下表面がすでに 36°C に制御できているという意味ではありません。

## ケースと呼吸を模した拡散

CO₂ 噴出口とヒーター付き人工皮膚を **10cm 角のケース**に格納し、ケースの下面に **5V ファン**を取り付けます。ファンで CO₂ と靴下の匂いを **4〜6秒間隔**で拡散し、動物の呼吸を模したリズムを作る設計です。

ファンの間欠動作は **555 タイマー IC**を使って実装します。ESP32-S3 のソフトウェアでこの周期を生成する仕様ではなく、555 のタイマー回路として設計します。ファン用電源は 5V とし、555 の型番・電源条件・負荷駆動回路は部品選定時に具体化します。

- ケースは 10cm × 10cm の寸法指定として記録し、高さと内寸・外寸の区別は未確定です。
- 「4〜6秒間隔」の ON 時間・OFF 時間の内訳と、固定周期を調整するのか周期を変動させるのかは未確定です。
- 下面のファンの送風方向、吸気口・排気口、CO₂ 噴出口と人工皮膚の配置は今後設計します。
- ケース内に格納する指定は CO₂ の**噴出口**と人工皮膚です。重曹・クエン酸の反応容器の配置は未確定です。

このファンは誘引源の拡散用です。捕獲時の吸引は、別の掃除機とサーボで行います。呼吸を模した拡散による誘引効果は未検証です。

## 動作の流れ

1. **CO₂ で誘引する。** 重曹とクエン酸で発生させた CO₂ を利用します。
2. **人工皮膚に近づける。** 半日以上履いた靴下の匂いと、36°C のヒーターによる加温を組み合わせます。10cm 角のケース下面の 5V ファンを 555 タイマーで間欠動作させ、CO₂ と匂いを 4〜6秒間隔で拡散します。
3. **接近を影として検出する。** 人工皮膚に接近する蚊が赤外線 LED の光を遮る変化を、赤外線受光素子で読み取ります。
4. **影の動きを認識する。** トンボの複眼を模した受光素子の配列から、遮光位置の時間変化を取得します。
5. **吸い込む。** ESP32-S3 がサーボモータを動かし、掃除機のトリガーを機械的に操作して蚊を吸い込みます。

これは狙う誘引・捕獲の順序です。拡散ファンの間欠動作は指定されていますが、CO₂ の発生・供給そのものやヒーターを同じ周期で ON/OFF する仕様は指定されていません。

```text
重曹 + クエン酸 → CO₂ 噴出口 ┐
                             ├ 10cm 角のケース
靴下 + 36°C ヒーター → 人工皮膚 ┘
                             ↓ ケース下面
555 タイマー → 駆動回路 → 5V 拡散ファン
                             ↓ 4〜6秒間隔で CO₂ と匂いを拡散
                            蚊を誘引・接近
赤外線 LED → 蚊による遮光 → 複眼状の赤外線受光素子配列
                            ↓ 各受光素子の時系列データ
                       ESP32-S3
                            ↓ 接近判定
                      サーボモータ
                            ↓ トリガーを操作
                         掃除機 → 吸引
```

## 複眼状の受光配列

赤外線受光部は、トンボの複眼を模した配列とします。単一受光素子の ON/OFF だけでなく、複数の受光素子に現れる蚊の影の移動を認識する方針です。配列の形状・個数・間隔・向き、LED との位置関係、各素子が見る範囲は今後設計します。

読み取り方式の初期案は次のとおりです。これは実装済みのアルゴリズムではありません。

- 各受光素子の明るさを時系列で取得し、蚊がいないときの基準値との差を求める。
- 隣接する素子の変化と時刻の関係から影の移動を候補として抽出する。
- 検出領域と人工皮膚・吸込口の位置関係を使い、吸引を開始する条件を決める。

影だけで蚊と断定できるかは未検証です。外光、靴下の揺れ、他の物体による変化を含め、誤検出と見逃しを実験で評価します。

## 実装前に具体化する項目

| 部分 | 決める内容 |
| --- | --- |
| CO₂ 発生部 | 反応容器の配置、反応の開始方法、放出量と持続時間、ケース内の噴出口位置 |
| ケース・拡散部 | 10cm 角の高さ・内外寸、開口部、下面ファンの送風方向・型番・電流 |
| 555 タイマー回路 | IC 型番、電源条件、ON/OFF 時間、周期の調整方式、抵抗・コンデンサー、ファン駆動回路 |
| 人工皮膚 | 靴下の固定方法、ヒーター仕様、温度の測定位置、温度制御・過熱時の停止方法 |
| 赤外線光学系 | LED 波長・配置、受光素子の種類・個数・配列、遮光の光路、外光への対処 |
| 信号処理 | 読み取り回路、サンプリング周期、基準値、移動判定、吸引開始条件 |
| 吸引部 | 掃除機の型番、吸込口の位置、トリガーの必要な力・ストローク、サーボ仕様 |
| 動作制御 | サーボの押下・解放位置、吸引時間、復帰時間、再検出までの待機時間 |
| 電源・配線 | 5V ファン・555・ESP32-S3・ヒーター・サーボの給電方法、駆動回路、GPIO 割当 |

CO₂ 発生を ESP32-S3 から自動制御する機構は、現時点では指定されていません。まず誘引源として扱い、自動制御が必要かは後で決めます。
